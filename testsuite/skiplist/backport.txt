# --- KNOWN BUG, DELIBERATELY ACCEPTED -------------------------------------
# Everything above is a feature or helper this branch does not have.  This one
# is different: it is a REAL DEFECT in this branch that we have chosen to ship.
#

# process's current directory instead of the destination -- silently, with exit

# that catches it.  Stock 3.2.7 fails the same way when given -s; v3.4.1 and
# 3.5.0 are unaffected; the breakage predates every security commit on this
# branch.  Full analysis, including the strace and what was ruled out, is in
# dev-notes/v327-backport-remote-option-wrong-dir.txt.
#
# Remove this line if that bug is ever fixed -- it is the only thing watching
